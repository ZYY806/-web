## 一、项目介绍

德州是一座被低估的城市：京杭大运河穿城而过，有"天下第一鸡"美誉的德州扒鸡，
还有董仲舒、颜真卿等历史名人的足迹。但它的文旅信息散落在各个平台，游客要来回
切换多个网站才能做一份攻略；本地居民与大学生也缺少一个"周末去哪儿"的聚合入口。

**本项目以 AI 为主、网页为辅**，围绕「AI 导游 · 小德」构建了六大 AI 能力，
把德州文旅信息聚合为一个智能化的城市文旅服务平台：

| AI 能力 | 说明 | 对应评审考点 |
|---|---|---|
| 📷 **照片 → 路线 + 拍摄点位**（主打） | 游客把在网上看到的德州风景照上传，多模态大模型先认出画面里的地点，再用站内真实数据（22 个拍摄机位、6 条主题路线、9 处游玩地）排出一条顺路的拍照路线，逐条给出机位、最佳时间与拍摄手法；非德州照片会礼貌提示并引导选择地点，无 Key 时降级为规则引擎，**一样能出结果** | 多模态能力、AI 工作流 |
| 🤖 AI 导游问答（RAG） | 站内数据实时检索（TF-IDF 式）+ 大模型生成，**SSE 流式输出**、思考状态可视化、回答带来源引用卡片；支持语音输入与语音播报 | 大模型集成、RAG |
| 🗺️ AI 行程规划师（Agent） | 用户一句话提需求，Agent 通过 **Function Calling** 自主调用 6 个站内工具（查景点/查美食/查演出/查场馆/查路线/查机位），多轮工具调用后输出结构化行程卡片，展示真实工具调用轨迹 | Agent / 工作流、MCP式工具集成 |
| 📷 拍照识德州（多模态） | 上传照片，多模态大模型识别美食/景点并讲门道；无 Key 时降级为站内热门推荐 | 多模态能力 |
| 🎯 AI 游玩画像 | 分析用户发帖/评论，生成兴趣标签 + 个性化推荐，首页展示"为你推荐" | 个性化、社会价值 |
| ✨ AI 文案生成 + 安全可控 | 详情页一键生成种草文案；敏感词过滤、情感分析、免责声明、限流、降级保命 | AI 安全与可控性 |

## 二、技术架构

### 技术栈选型

- **后端**：Python + Flask（轻量、易部署，后端仅作为 AI 能力接入层，符合赛项"前端为主体"的要求）
- **前端**：HTML5 + CSS3 + 原生 JavaScript（ES6，模块化拆分：`main.js` / `ai-assistant.js` / `ai-extra.js` / `photo-plan.js` / `wall.js`），Fetch + **SSE 流式渲染**
- **数据层**：纯 Python 数据模块 `data_store.py`（文旅内容写死在代码里，开箱即用）+ `data/store.json`（游客帖子/留言存档，重启不丢）——**不需要安装任何数据库**
- **地图服务**：百度地图开放平台 JS API（WebGL 版）
- **大模型**：OpenAI 兼容协议（火山方舟豆包 / DeepSeek / 智谱 GLM 可一键切换），支持 **stream=true 流式**、**Function Calling**、**多模态 image_url**

### 系统架构

```
浏览器（HTML/CSS/JS + SSE 流式渲染 + 语音交互 + 百度地图）
      │  页面交互 / 流式对话 / 上传照片 / 点赞留言
      ▼
Flask（Python 后端 app.py —— AI 能力接入层）
      │  /api/photo-plan    ★ 照片 → 路线 + 拍摄点位（主打）
      │  /api/chat/stream   RAG 流式问答（SSE）
      │  /api/agent/plan    Agent 行程规划（Function Calling）
      │  /api/vision        多模态识图
      │  /api/copy          AI 文案生成
      │  /api/profile       AI 游玩画像
      │  /api/wall/cloud    AI 词云（本地分词统计）
      ▼
ai_assistant.py（AI 能力中心：检索 / 工具 / 提示词 / 降级 / 安全过滤）
      │                        │
      ▼                        ▼
data_store.py（纯代码数据层  大模型 API（OpenAI 兼容协议）
  + data/store.json 存档）
```

## 三、环境配置与安装运行

### 1. 环境要求

- Python 3.10+（推荐 3.13）
- ~~MySQL~~ **不需要了**：数据全部内置在代码里，装好 Python 就能跑

### 2. 配置环境变量（重要，涉及密钥安全）

```bash
# Windows PowerShell
Copy-Item .env.example .env
```

打开 `.env` 按需填写（所有 API 密钥只存本机，`.gitignore` 已确保不上传）：

| 变量 | 说明 |
|------|------|
| `SECRET_KEY` | 会话加密密钥（改成自己的长随机串） |
| `BAIDU_MAP_AK` | 百度地图 AK（申请：https://lbsyun.baidu.com） |
| `CONTACT_EMAIL` / `SMTP_*` | 联系我们页真实发信配置 |
| `AI_API_BASE / AI_API_KEY / AI_MODEL` | 大模型接入（不填 Key 自动降级） |
| `AI_VISION_MODEL` | 多模态识图模型（照片排路线 / 拍照识德州用，留空则用 AI_MODEL） |

> 不再需要任何 `DB_*` 数据库配置。

> ⚠️ **安全提醒**：API 密钥通过环境变量配置，绝不出现在代码与公开仓库中（赛项要求）。

### 3. 安装依赖并启动

```bash
pip install -r requirements.txt
python app.py
```

看到 `德州文旅网站已启动（数据全部内置，无需数据库）` 后，浏览器打开 **http://127.0.0.1:5000** 即可。
文旅数据全部内置；游客发的帖子、评论、留言会存到 `data/store.json`，重启不丢。

- 演示账号：`demo` / `123456`
- 管理员账号：`admin` / `admin888`（发布官方实拍帖）

### 4. AI 能力说明（重要）

| 配置状态 | 表现 |
|---|---|
| 已填 `AI_API_KEY` | 全部 AI 能力完整启用：照片识别并排路线、流式大模型回答、Agent 工具调用规划、多模态识图 |
| 未填 Key / 调用失败 | 自动降级：规则引擎照样排路线+机位、站内知识库成文回答、规则版行程规划、热门推荐兜底——**演示现场断网也不开天窗** |

## 六、常见问题

| 问题 | 处理 |
|------|------|
| 启动报数据库错误 | 本版本已无数据库；确认运行的是新版 `app.py`，删除旧的 `__pycache__` 后重试 |
| AI 回答显示"演示模式" | `.env` 未配 `AI_API_KEY`，填好后重启即可 |
| 照片排路线认不出地点 | 正常现象，页面会引导你从站内地点中挑一个，照样生成路线和机位 |
| 语音输入没反应 | 用 Chrome / Edge 打开网站并允许麦克风权限 |
| 地图页空白 | `.env` 未配 `BAIDU_MAP_AK`，去百度地图开放平台免费申请 |
