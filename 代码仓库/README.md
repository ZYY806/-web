# 九达天衢 · 韵动德州 — 一站式德州文旅信息平台

一个 **Python + Flask + MySQL** 的动态 Web 网站，把分散在多个平台上的德州文旅信息
（公交可达的游玩地、网红餐厅、文化场馆、小剧场演出、城市漫游路线）**聚合到一个网站**，
并在此基础上提供了 **UGC 论坛社区**、**百度地图可视化**、**邮箱联系反馈**等创新功能，
让游客「一个网站玩转德州」。

> 项目名称：三个臭皮匠 — 九达天衢 · 韵动德州
> 参赛作品：XX 杯 作品提交 · 代码仓库

## 一、项目介绍

德州是一座被低估的城市：京杭大运河穿城而过，有“天下第一鸡”美誉的德州扒鸡，
还有董仲舒、颜真卿等历史名人的足迹。但它的文旅信息散落在各个平台，游客往往要
来回切换多个网站才能做一份攻略。

**本项目把散落信息整合为一个站点**，实现「查游玩地 → 看公交路线 → 找美食 → 逛文化场馆 →
看演出 → 规划漫游路线 → 上论坛问路」的全流程，真正让游客只用打开一个网站。

### 功能页面

| 页面 | 网址 | 内容 |
|------|------|------|
| 首页 | `/` | 栏目入口 + 热门推荐 + 最新帖子 + 宣传视频 |
| 公交游德州 | `/attractions` | 公交可达的商场/公园/夜市/景点，附公交路线 |
| 美食打卡 | `/food` | 扒鸡、驴肉火烧等网红餐厅热榜 |
| 文化场馆 | `/culture` | 图书馆、博物馆、文化馆、纪念馆 |
| 小剧场 | `/theater` | 音乐剧、相声、脱口秀、评剧 |
| 漫游路线 | `/routes` | 按美食/文化/亲子/文艺排好的一日游路线 |
| 智慧地图 | `/map` | 百度地图标注景点/美食/文化场馆（创新点） |
| 驴友广场 | `/forum` | 看帖、发帖、点赞、评论（UGC 社区，需登录，可上传配图） |
| 联系我们 | `/contact` | 留言表单 + 团队邮箱（创新点） |
| 登录 / 注册 | `/login` `/register` | 注册账号、登录 |

### 核心创新点（详见技术报告）

1. **多源信息聚合**：把分散在多个网站的德州文旅信息整合为一个站点，一站式查询。
2. **百度地图可视化**：集成百度地图开放平台 JS API，景点/美食/文化场馆一键标注在地图上。
3. **UGC 论坛社区**：用户注册登录后可发帖、评论、点赞，形成用户生成内容的社区。
4. **公交可达性数据**：每个游玩地都标注公交路线，服务公共交通出行的游客。
5. **邮箱联系反馈**：站内留言表单 + 团队邮箱，用户反馈直达团队。
6. **团队实拍内容**：预置管理员账号，用团队实拍的德州照片（博物馆/银座/公交站等）发布带图实拍帖，游客登录后也可上传配图发帖。

## 二、技术架构

### 技术栈选型

- **前端**：HTML + CSS + JavaScript（原生实现，无重型框架）
- **后端**：Python + Flask（轻量、对新手友好、易于部署）
- **数据库**：MySQL（使用 pymysql 驱动）
- **地图服务**：百度地图开放平台 JS API（WebGL 版）

### 系统架构

```
浏览器（HTML/CSS/JS 界面 + 百度地图）
      │   用户在页面点按钮、发帖、看地图
      ▼
Flask（Python 后端 app.py）
      │   处理请求、增删改查、渲染模板
      ▼
MySQL（数据库 dezhou_tour：用户/景点/餐厅/文化/剧场/路线/帖子/评论/留言）
```

### 目录结构


## 三、环境配置与安装运行

### 1. 环境要求

- Python 3.10+（推荐 3.13）
- MySQL 5.7 / 8.0（本机已装好）

### 2. 配置环境变量（重要，涉及密钥安全）

1. 复制项目根目录下的 `.env.example` 为 `.env`：

   ```
   # Windows PowerShell
   Copy-Item .env.example .env
   ```

2. 打开 `.env`，按需填写：

   | 变量 | 说明 | 示例 |
   |------|------|------|
   | `DB_HOST` | 数据库地址 | `localhost` |
   | `DB_USER` | 数据库用户名 | `root` |
   | `DB_PASSWORD` | 数据库密码（本机为空则留空） | 空 |
   | `DB_NAME` | 数据库名（程序自动创建） | `dezhou_tour` |
   | `DB_PORT` | 数据库端口 | `3306` |
   | `SECRET_KEY` | 会话加密密钥（改成自己的长随机串） | `xxxxxx` |
   | `BAIDU_MAP_AK` | 百度地图开放平台密钥（申请：https://lbsyun.baidu.com） | 可选 |
   | `CONTACT_EMAIL` | 联系我们的接收邮箱 | `xxx@xx.com` |

   > ⚠️ **安全提醒**：`.env` 已被 `.gitignore` 忽略，绝不会上传到公开仓库；
   > API 密钥必须通过环境变量配置，不要把密钥写死在代码里。

### 3. 安装依赖

```bash
pip install -r requirements.txt
```

### 4. 启动 MySQL

- 本机便携版：运行 `D:\hygwlw_mysql\mysql-8.0.26-winx64\startConsole.bat`（别关黑窗口）；
- 或打开系统“服务”，启动 `MySQL-Hygwlw` 服务。

### 5. 启动网站

```bash
python app.py
```

看到下面提示即成功：

```
德州文旅网站已启动！
请在浏览器打开： http://127.0.0.1:5000
```

浏览器打开 **http://127.0.0.1:5000** 即可访问。停止运行：`Ctrl + C`。

> 程序启动时会**自动建库建表并填入示例数据**，无需手动创建。
> 演示账号：用户名 `demo`，密码 `123456`。
> 管理员账号：用户名 `admin`，密码 `admin888`（发布实拍帖的官方账号）。
